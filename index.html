ShopCluster

Customer segmentation with K-Means clustering. Trained on 300 synthetic shoppers, the model finds 4 natural groups — no labels needed, the clusters emerge from the data. Silhouette score: 0.53 (0 = overlapping, 1 = perfectly separated).

How it works

  1. Each shopper is a point in 3-D: age, income, spending score.
  2. Features are standardised (mean 0, spread 1) so income does not swamp age.
  3. K-Means starts with 4 centres and moves them until shoppers stop switching groups.
  4. A new shopper joins the segment whose centre is nearest — the exact same centres run here in JavaScript, no server needed.
